# Button

Buttons communicate action items to indicate user interaction hotspots.

</header>

## About

The Button is a clickable UI element used to trigger actions or navigate users to different sections of the application. It serves as a key interactive element, guiding users toward primary and secondary actions. Buttons can vary by style, size, and state, depending on their purpose and priority within a page.

## When to Use

Buttons communicate actions that users can take. They are commonly found throughout the interface in areas such as:

- Dialogs
- Modal windows
- Forms
- Cards

**Use buttons when:**

- The user needs to trigger an action (save, submit, confirm, apply, upload, continue).
- You need to move the user to the next step in a flow.
- The action is important and should be clearly visible and accessible.
- A clear call-to-action is required.
