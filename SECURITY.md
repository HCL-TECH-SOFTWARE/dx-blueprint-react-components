# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a Vulnerability

**Please do NOT open a public GitHub issue for security vulnerabilities.**

If you discover a security vulnerability in this project, please report it responsibly through one of the following channels:

1. **GitHub Security Advisories (preferred):** Use the [Report a vulnerability](https://github.com/HCL-TECH-SOFTWARE/dx-blueprint-react-components/security/advisories/new) feature in the Security tab of this repository. This allows for private discussion and coordinated disclosure.

2. **Email:** Contact the HCL Open Source Project Office at [ospo.hclsoftware@hcl.com](mailto:ospo.hclsoftware@hcl.com).

## What to Include

When reporting a vulnerability, please provide:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- The version(s) affected
- Any suggested fix or mitigation (if available)

## Response Timeline

- We will acknowledge receipt of your report within **5 business days**.
- We will provide an initial assessment and expected timeline for a fix within **10 business days**.
- We will notify you when the vulnerability has been fixed and a patched version is available.

## Disclosure Policy

We follow a coordinated disclosure process. We ask that you:

- Allow us reasonable time to investigate and address the issue before public disclosure.
- Avoid exploiting the vulnerability beyond what is necessary to demonstrate it.
- Do not access or modify other users' data.

## More Information

For details on HCL Software's vulnerability management program, see the [HCL Software Vulnerability Disclosure Policy](https://support.hcl-software.com/csm?id=kb_article&sysparm_article=KB0069899).
