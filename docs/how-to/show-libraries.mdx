# Show Libraries in Authoring

This guide provides instructions on how to show libraries in the Authoring portlet in HCL Digital Experience (DX).
</header>

## Introduction

The [Authoring portlet](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/authoring_portlet/) in HCL DX allows you to manage web content libraries. By default, some libraries may not be visible in the Authoring portlet. This guide will help you [select and show the libraries](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/authoring_portlet/auth_portlet_settings/wcm_config_authoringportlet_libraries/) you need.

## Prerequisites

1. You have access to the Authoring portlet.
2. You have access to the libraries you want to show.

## Steps to Show Libraries in Authoring

1. Go to **Open Applications Menu \> Web Content**.
2. Expand the navigation menu and open the **Authoring** portlet.
3. Open **Preferences \> Edit Shared Settings**.
4. Under **Library Selection**, add the required libraries.  
   ![](./docs/how-to/show-libraries/edit-shared-settings.png)
5. Click **OK** to save changes.
6. The libraries will now appear under the **Library Explorer**.  
   ![](./docs/how-to/show-libraries/library-explorer.png)
