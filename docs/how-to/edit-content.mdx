# Edit Content

Learn how to edit content of a Blueprint component on a page of a HCL Digital Experience (DX) site that is using the Blueprint design system.
</header>

## Introduction

In HCL Digital Experience (DX), content items can be edited using many different ways. Follow this guide if you want to edit the content of a Blueprint page component on your page. To learn more about web content management in HCL DX, please refer to the [HCL DX Help Center](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/).

## Steps to Edit Content

1. Turn on **Edit Mode** from the Site Manager toolbar.   
2. On your page, find and choose a page component that has a <i class="ci-Edit_Pencil_Line_01" /> icon button attached to it. Only Blueprint page components that support editing content will have this icon.
    ![](./docs/how-to/create-content-5.png).  
3. Click on the <i class="ci-Edit_Pencil_Line_01" /> icon button to start editing the page component's content.
    ![](./docs/how-to/create-content-7.png) 
    <br/>
    <Admonition type="note">
    The content fields on the form vary based on the [content template](?path=/docs/information-architecture-content-types--documentation) that is being used by the page component where you are adding the content.
    </Admonition>
4. Edit the details as much as you like then save your changes by clicking the **Save and Close** button.  
5. Finally, verify that your changes are displayed correctly in the page component.
