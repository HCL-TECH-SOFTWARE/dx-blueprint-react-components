# Remove Blueprint in Traditional Deployments

Learn how to remove the Blueprint design system in HCL Digital Experience (DX) traditional deployments.
</header>

# Introduction

There are multiple ways to remove the Blueprint design system from an HCL DX Traditional deployment depending on your operational needs. You can choose to automate the removal during your next CF upgrade by configuring Resource Environment Provider (REP) properties, or you can perform an immediate removal manually using the ConfigEngine command-line interface.

# Prerequisites

* You have administrator access to the HCL Digital Experience (DX) instance.

## Removing Blueprint from the Base Portal via REP properties

1. Configure the REP properties for the Blueprint Design System, by following the [standard process for managing Resource Environment Providers](https://help.hcl-software.com/digital-experience/9.5/latest/deployment/manage/config_portal_behavior/service_config_properties/)

2. Remove the Blueprint Assets or the Nex Haven sample site by updating the existing properties or creating the required ones (`blueprint.enable.assets` and `blueprint.enable.nex.haven`) and set their values to false.

3. Perform a CF Upgrade. During the upgrade, the system will apply the values you set, removing the Blueprint Assets or the Nex Haven sample site accordingly.

4. Verify that the Blueprint has been removed successfully by checking your base portal for the following:
    * The **Nex Haven** site is **not** listed under the **Site Menu** on the [Site Manager](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/inline_editing/) toolbar or **Sites** in [Practitioner Studio](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/practitioner_studio/).
    * The Blueprint libraries are **not available** in the [Web Content Libraries](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/authoring_portlet/web_content_libraries/) portlet.

**Note:** If `blueprint.enable.assets` is set to false (Blueprint Assets are removed), the Nex Haven sample site will not be deployed, even if `blueprint.enable.nex.haven` is set to true.

## Steps to Remove Blueprint using ConfigEngine tasks

1. Open a command prompt and navigate to **wp_profile_root/ConfigEngine**

2. Run the following configuration task; replace the placeholders with your actual values:
    ```
    UNIX™Linux™:
    ./ConfigEngine.sh blueprint-remove-wcm-libraries -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ./ConfigEngine.sh blueprinttheme-unregister-theme-in-portal -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ./ConfigEngine.sh blueprinttheme-remove-pages -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ./ConfigEngine.sh blueprinttheme-remove-theme-ear -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ./ConfigEngine.sh action-remove-ear-wp.theme.blueprintmodule -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>

    Windows™:
    ConfigEngine.bat blueprint-remove-wcm-libraries -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ConfigEngine.bat blueprinttheme-unregister-theme-in-portal -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ConfigEngine.bat blueprinttheme-remove-pages -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ConfigEngine.bat blueprinttheme-remove-theme-ear -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ConfigEngine.bat action-remove-ear-wp.theme.blueprintmodule -DWasPassword=\<wasAdminPassword\> -DPortalAdminPwd=\<portalAdminPassword\>
    ```
    <Admonition type="warning">
    To avoid conflicts caused by interdependencies, removal steps must be executed in the specified order. 
    </Admonition>
3. Verify that the Blueprint has been removed successfully by checking your portal for the following:
    - The **Nex Haven** site is no longer listed under the **Site Menu** on the [Site Manager](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/inline_editing/) toolbar or **Sites** in [Practitioner Studio](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/practitioner_studio/).
    - The Blueprint libraries are not available in the [Web Content Libraries](https://help.hcl-software.com/digital-experience/9.5/latest/manage_content/wcm_authoring/authoring_portlet/web_content_libraries/) portlet.
    - The Blueprint theme is no longer listed on the [Theme Editor Portlet](https://help.hcl-software.com/digital-experience/9.5/latest/build_sites/themes_skins/customizing_theme/theme_editor_portlet/)

## CF Rollback

Performing a [CF Rollback](https://help.hcl-software.com/digital-experience/9.5/latest/deployment/install/traditional/cf_install/ccf_95_standalone/#steps-for-rolling-back-the-cumulative-fix) to a CF version lower than CF229 will remove the Blueprint design system bundle.
