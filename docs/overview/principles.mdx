# Principles

The focus of our Blueprint is **YOUR** user.
</header>

## With a list of principles, we provide:

| | |
| ------ | ------ |
| ![](./docs/overview/principles-1.svg) | **CONTENT FIRST** <br/><br/> Our users' content always comes first - if faced with a choice between introducing a zeroheight branding element and making user content stand out, we always choose the latter. |
| ![](./docs/overview/principles-2.svg) | **SMART DEFAULTS** <br/><br/> We prefer giving users sensible defaults instead of burdening them with a choice they don't need to make. |
| ![](./docs/overview/principles-3.svg) | **JUST-IN-TIME** <br/><br/> We choose to display UI elements only when they are needed, rather than make them available at all times. |
| ![](./docs/overview/principles-4.svg) | **CONTENT AUTHORS' ENABLER** <br/><br/> A friendly authoring environment focused on fast adoption and the experience Authors have to create a unique experience. |
| ![](./docs/overview/principles-5.svg) | **TEMPLATES FOCUSED ON USER NEEDS** <br/><br/> Providing intuitive navigation and a pleasant user experience for all audiences of your platform. |
| ![](./docs/overview/principles-6.svg) | **IN CONTEXT AND IN THE RIGHT TIME...** <br/><br/> We offer hyper personalized experiences via a classification system that organizes content for authors and personalized delivery based on audiences. |
| ![](./docs/overview/principles-7.svg) | **... FOR THE RIGHT USER** <br/><br/> A personalization and security model to deliver the allowable content to the right person as needed, and an audience manager to ensure the delivery is accurate. |
| ![](./docs/overview/principles-8.svg) | **"TWO STEPS" AHEAD OF THE USER** <br/><br/> The user journeys are always focused on transactions, and search functionality supports faceted search and provides suggestions and anticipates what a user might be looking for. |
| ![](./docs/overview/principles-9.svg) | **COMPREHENSIVE USER MODEL** <br/><br/> A user profile structure to support personalization and social collaboration. |
| ![](./docs/overview/principles-10.svg) | **READY FOR YOUR ORG STRUCTURE. <br/> WHATEVER IT IS.** <br/><br/> A governance structure that assures content approval and content placement through workflow processes. |
